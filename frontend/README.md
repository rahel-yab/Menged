# Menged frontend

The frontend is a React and TypeScript app built with Vite. For setup, local development, configuration, and build instructions, see the [project README](../README.md).

From this directory, install dependencies and start the development server:

```powershell
npm.cmd ci
npm.cmd run dev
```

The Vite development server forwards `/api` requests to the backend at `http://localhost:3000`.
